# Marca Xila

La greca de Mitla bordada en punto de cruz: cada puntada es una X, la inicial, y la última, en
cobalto, es el último valor (la regla de la anatomía editorial hecha bordado). Fuente de verdad:
la página de identidad; aquí viven los archivos que usan el README, el sitio y la plantilla.

| Archivo                             | Uso                                                                 |
| ----------------------------------- | ------------------------------------------------------------------- |
| `xila.svg`                          | Wordmark (símbolo + «xila»); hereda `currentColor` y `--xila-color` |
| `xila-claro.svg`, `xila-oscuro.svg` | Wordmark con colores fijos, para `<img>` y `<picture>`              |
| `simbolo*.svg`                      | Símbolo de 17 puntadas, mínimo 24 px                                |
| `favicon.svg`                       | 9 puntadas sobre cobalto, para pestañas (16 a 48 px)                |
| `avatar.svg`, `icono.svg`           | Avatar redondo (GitHub, npm) e icono de app                         |

Reglas: la última puntada siempre en color; no rellenar ni girar la greca ni cambiar el grosor;
espacio libre alrededor de al menos una puntada; el hilo no se usa como texto sobre manta.
