# Marca Xila

La greca de Mitla bordada en punto de cruz: cada puntada es una X, la inicial, y la última, en
cobalto, es el último valor. Paleta Cobalto: manta `#f6f1e8`, tinta `#15171f`, cobalto `#1f4bd8`
(oscuro `#7a9bff`), hilo `#d14e0a` (oscuro `#ff8a3d`).

| Archivo                                      | Uso                                                                       |
| -------------------------------------------- | ------------------------------------------------------------------------- |
| `wordmark-claro.svg` / `wordmark-oscuro.svg` | Símbolo + nombre: README, portada del sitio. Mínimo 96 px de ancho.       |
| `simbolo-claro.svg` / `simbolo-oscuro.svg`   | Símbolo de 17 puntadas: logo de la barra del sitio. Mínimo 24 px.         |
| `favicon.svg`                                | Versión de 9 puntadas para 16–48 px; cambia sola con el tema del sistema. |
| `avatar.svg`                                 | Avatar de GitHub y npm (círculo cobalto).                                 |
| `icono-app.svg`                              | Ícono de docs y app (cuadrado redondeado).                                |

Reglas: la última puntada siempre en color (es el dato); al menos una puntada de espacio libre;
no rellenar las puntadas, no cambiar su grosor, no girar la greca, no usar el hilo como texto
sobre manta.
