# Fuentes de la marca

Instrument Sans, JetBrains Mono y Fraunces, bajo la SIL Open Font License (`OFL-*.txt`), en
dos formas: `*.woff2` recortadas a latín (las que carga `xila.css`) y `ttf/` completas, que CI
instala en el sistema para que Chromium mida el texto igual que en las capturas de referencia.
